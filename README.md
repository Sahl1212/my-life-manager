# ⚡ إدارة حياتي | Life Manager

تطبيق ويب شخصي متكامل لإدارة المهام والجدول اليومي، تتبع العادات، وإدارة الماليات والميزانية باستخدام **Flask** وقاعدة بيانات **SQLite**.

## 🔧 ماذا تم إصلاحه وتطويره؟ (What Was Fixed & Added)

1. **إصلاح مشكلة القوالب والتنسيق (`base.html` & `home.html`)**:
   - كان ملف `base.html` موجوداً في المجلد الرئيسي خارج `templates/`، وكان ملف `home.html` يفتقد وسم الوراثة `{% extends "base.html" %}` في بدايته، مما منع تحميل ملفات `style.css` و`script.js`.
   - تم نقل `base.html` إلى داخل `templates/base.html` وتوحيد القائمة الجانبية (`sidebar`) والشريط العلوي (`top-header`) فيه بحيث ترثه جميع الصفحات تلقائياً.
2. **إضافة قاعدة البيانات (`database/`)**:
   - `database/schema.sql`: يحتوي على تصميم الجداول الأربعة (`tasks`, `habits`, `transactions`, `settings`).
   - `database/db.py`: يحتوي على دوال بايثون واضحة ومقسّمة لقراءة، إضافة، تعديل، وحذف البيانات.
   - `database/life_manager.db`: ملف قاعدة البيانات الفعلي من نوع SQLite (يتم إنشاؤه وتعبئته ببيانات أولية تلقائياً عند التشغيل).
3. **إضافة الصفحات الثلاث المطلوبة (`templates/`)**:
   - `schedule.html` (`/schedule`): صفحة الجدول والمهام (إضافة مهمة بتصنيف وأولوية وتاريخ ووقت، تصفية المهام، تعليم المهام كمكتملة، أو حذفها).
   - `habits.html` (`/habits`): صفحة تتبع العادات (إضافة عادة بأيقونة وهدف أسبوعي، تسجيل الإنجاز اليومي لحساب سلسلة الأيام Streak 🔥، تصفير العداد، أو الحذف).
   - `finance.html` (`/finance`): صفحة الماليات والميزانية (حساب الرصيد الصافي، إجمالي الدخل، مصروفات الشهر، تحديد الميزانية الشهرية وشريط الاستهلاك، وتفصيل المصروفات حسب التصنيف).

## 📁 هيكل المجلدات والملفات (Project Structure)

```text
Life Manger/
├── base.py                 # الملف الرئيسي لتشغيل خادم Flask وجميع المسارات (Routes)
├── README.md               # دليل الاستخدام والتعديل
├── database/
│   ├── __init__.py         # تعريف حزمة قاعدة البيانات
│   ├── db.py               # دوال التعامل مع قاعدة البيانات (SQLite)
│   ├── schema.sql          # تصميم جداول قاعدة البيانات
│   └── life_manager.db     # ملف قاعدة البيانات الفعلي
├── static/
│   ├── style.css           # التنسيقات (الوضع الداكن/الفاتح + تجاوب الشاشات)
│   └── script.js           # الترجمة الفورية (عربي/إنجليزي) وحفظ الإعدادات
└── templates/
    ├── base.html           # القالب الأساسي المشترك (Sidebar + Header)
    ├── home.html           # الصفحة الرئيسية (Dashboard)
    ├── schedule.html       # صفحة الجدول والمهام
    ├── habits.html         # صفحة تتبع العادات
    └── finance.html        # صفحة الماليات والميزانية
```

## 🚀 طريقة التشغيل (How to Run)

1. تأكد من تثبيت مكتبة `flask`:
   ```bash
   pip install flask
   ```
2. شغّل الملف الرئيسي `base.py`:
   ```bash
   python base.py
   ```
3. افتح المتصفح على الرابط:
   ```text
   http://127.0.0.1:5000
   ```

## 🛠️ كيف تعدّل الكود بسهولة؟ (How to Customize)

- **تعديل الألوان أو الخطوط**: افتح `static/style.css` وعدّل المتغيرات في أعلى الملف تحت `[data-theme="dark"]` و `[data-theme="light"]`.
- **تعديل النصوص والترجمة**: افتح `static/script.js` وعدّل قاموس `translations` للقسمين `ar` و `en`.
- **إضافة حقل جديد في قاعدة البيانات**: أضف العمود في `database/schema.sql`، ثم حدّث دالة الإضافة في `database/db.py` والنموذج في صفحة القالب المقابلة داخل `templates/`.
